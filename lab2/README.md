# Лабораторная работа 2 по численным методам

Вариант 20. Реализованы методы простой итерации и Ньютона для уравнения и системы. В отчёте приведены решения, графический выбор начальных приближений и сравнение сходимости.

## Запуск

Нужен Python 3.9 или новее. Основные программы используют только стандартную библиотеку.

```bash
python lr2_1.py 1e-6
python lr2_2.py 1e-6
```

Можно запустить без аргумента: программа запросит точность с клавиатуры. Допустимо `1e-12 <= eps < 1`; ограничение снизу связано с вычислениями в формате float. Точность задаёт допустимую абсолютную погрешность, для системы используется максимум ошибок двух координат.

В консоль выводятся только найденные решения двумя методами и количество итераций. Начальное приближение считается итерацией 0; оно не входит в число выполненных шагов. Печать 12 знаков после точки не означает, что все эти знаки верны при любой заданной точности.

## Файлы

- `lr2_1.py` — задача 2.1, положительный корень `tan(x) - 5*x**2 + 1 = 0` на `[-1, 1]`.
- `lr2_2.py` — задача 2.2, положительное решение системы при `a = 2`.
- `report.pdf` — готовый отчёт с краткими алгоритмами, результатами и графиками.
- `analyze.py` — воспроизводит графики и таблицы анализа.
- `results/output.txt` — фактический вывод обеих программ при `eps = 1e-6`.
- `results/01_scalar_initial.png` — графический выбор начального приближения для уравнения.
- `results/02_system_initial.png` — графический выбор начального приближения для системы.
- `results/03_errors.png` — сравнение погрешности по итерациям для обоих методов.
- `results/04_iteration_counts.png` — число итераций при разных значениях точности.
- `results/task*.csv` — приближения, погрешности и оценки погрешности на каждом шаге при `eps = 1e-6`.
- `results/precision_comparison.csv` — сравнение методов при разных значениях точности.

В исходном задании `lg` означает десятичный логарифм; в программе используется `math.log10`. Все тригонометрические функции вычисляются в радианах.

## Повторное построение графиков

Только для анализа нужен дополнительный пакет Matplotlib:

```bash
python -m pip install matplotlib
python analyze.py 1e-6
```

Графики и CSV обновляются в папке `results`. PDF содержит результаты для `eps = 1e-6` и автоматически не меняется при запуске `analyze.py`.

Столбец `error` / `error_inf` — ошибка относительно независимого эталона: метод половинного деления с арифметикой Decimal и 60 значащими цифрами. Для системы сначала исключается вторая переменная. Эталон служит только для анализа и не используется в решающих программах. Столбец `step` / `step_inf` — разность соседних приближений; это другая величина. Столбец `error_bound` — теоретическая верхняя оценка ошибки; вблизи машинной точности она также подвержена округлению. На графике ошибок точки ниже `5e-15` не показаны, но они сохранены в CSV.
